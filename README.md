# Calculadora-con-M-todos.
# Descripción.
Este programa fue desarrollado en C# con el propósito de aplicar los conocimientos que vimos en clase. Es una calculadora con métodos, haciendo que el usuario pueda realizar cálculos con dos números y eligiendo una de las operaciones que se emplean en el programa: suma, resta, multiplicación y división. 
<img width="1720" height="893" alt="image" src="https://github.com/user-attachments/assets/f377713d-5661-4731-b5b9-0c8af353221b" />
Aquí se puede ver como el programa muestra que el usuario puede escribir dos números, cuales quiera, y luego seleccionar la operación que quiere realizar con esos números, en este caso, se decidió dividir esos números, y este mismo se imprime en pantalla haciendo que el usuario vea dicho resultado.

En esta otra imagen que pasa lo mismo, con diferentes números y con una operación diferente logrando un resultado correcto, lo que indica que el programa responde de manera correcta sin importar los números ni la operación que le indiquemos al programa.
